## ✨ Engineering Highlights

- **Dark Glass Quant Aesthetic:** Zero childish emojis, calibrated high-contrast typography, subtle cyan/blue backglows, and CSS hardware-accelerated transitions.
- **Zero Third-Party Component Overhead:** Crafted purely in native CSS variables and React hooks without heavy chart libraries that introduce bundle bloat.
- **Sub-Millisecond Telemetry Simulation:** Dynamic interval hooks simulating live message ingestion (1,900+ msgs/sec), volatile agreement variance, and interactive circuit recalibration.
- **Responsive & Accessible:** Fully adaptive viewport scaling from ultra-wide trading desks down to mobile operator monitors with clean DOM semantics.

## 🚀 Local Development

```bash
# 1. Clone repository
git clone https://github.com/amazing200guy1-a11y/Sovereign-Cockpit-UI.git
cd Sovereign-Cockpit-UI

# 2. Install dependencies
npm install

# 3. Launch local development server
npm run dev
# Open http://localhost:3000

# 4. Production build verification
npm run build
```
